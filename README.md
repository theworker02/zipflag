# zipflag

Zip lightweight flag statistics from stdin samples.

**Site:** https://theworker02.github.io/zipflag/

## Install / run

```bash
git clone https://github.com/theworker02/zipflag.git
cd zipflag
node src/cli.js
node --test
```
